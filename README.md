# BINÔME STUDIO

Application professionnelle partagée pour la pâtisserie, la chocolaterie et la glacerie.

## Installation
- Node.js 22
- `npm install`
- Copier `.env.example` vers `.env.local` et renseigner les variables Supabase.
- `npm run dev` pour le développement.
- `npm run build` pour vérifier la compilation.

Le schéma initial de la base de données se trouve dans `supabase/schema.sql`.
